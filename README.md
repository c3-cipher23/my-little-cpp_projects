# 🌡️ Temperatur-Wandler (Mini-Tool)

Ein sehr einfaches C++-Programm, das Temperaturen von Celsius in Fahrenheit umrechnet. 
Dieses Projekt dient als Einstieg, um die Grundlagen der Sprache zu verstehen.

## ❓ Was macht das Tool?
Es ist ein kleines Konsolen-Programm mit drei einfachen Schritten:
1. Es fragt den Nutzer nach einer Temperatur in Celsius.
2. Es berechnet den Wert in Fahrenheit.
3. Es gibt das Ergebnis übersichtlich im Terminal aus.

## 🚀 Wie starte ich es?

Sie benötigen einen C++-Compiler (wie `g++`).

**1. Kompilieren**
Öffnen Sie das Terminal in diesem Ordner und geben Sie ein:
```bash
g++ -o temp_wandler main.cpp
